- Optional music player

## Add your chosen song
Put your own legally obtained/authorized MP3 file in this folder and name it exactly:

music.mp3

Then open the website and tap the Music button.

## Free publishing
### GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, e.g. `harshita-ujjwal-wedding`.
3. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and your `music.mp3` if desired.
4. In the repository, open Settings → Pages.
5. Choose “Deploy from a branch”, select `main` and `/root`, then Save.
6. GitHub will give you a free website link that you can share on WhatsApp.

No paid template or hosting is required.
